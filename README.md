# OCiper

A C program that can encrypt and decrypt the any binary data.
> ⚠️ please make sure that your file can be fit inside RAM or it will throw error 

## Technology 

-C

## Tested With 

- gcc (v15)
- std (c23)

## How To Run

- Use build file
- ./build run_encry encrypt yourfilename
- ./build run_decry decrypt your_encrypted_file your_key_file
